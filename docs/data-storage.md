# Рабочие файлы data

В папке остаются текущая база, общие выгрузки, рабочие отчёты, ограниченные
журналы, нужный кеш и исходники принятых серий для проверки. Старые поиски,
неудачные попытки, разовые аудиты и копии отдельных пар удалены.

## База

`data/qcross.db` — основное хранилище: 263 инструмента, 503 пары «тикер–валюта»,
361 179 месячных наблюдений, статусы импортов, методы и исторические ревизии.
Очистка файлов не изменяет базу или значения доходностей.

## Exports — готовые данные

| Файл | Содержимое |
| --- | --- |
| `lazyportfolio_instruments.csv` | Каталог: тикер, название, категория источника, базовая и доступные валюты, активность, статус загрузки базовой серии и число наблюдений. |
| `lazyportfolio_instruments.json` | Расширенный каталог с `raw_metadata`, исходными атрибутами селектора и временем обнаружения. Полей статуса загрузки из CSV в текущем JSON нет. |
| `lazyportfolio_monthly_returns.csv` | Все 361 179 наблюдений в длинном формате, с точным десятичным текстом извлечённых значений. |
| `lazyportfolio_monthly_returns.parquet` | Те же данные для Pandas/NumPy; сжатие и числовой формат `float64`. |
| `lazyportfolio_monthly_returns_wide.parquet` | Матрица в USD: 2 805 месяцев и 74 инструмента. Пропуски остаются `null`/`NaN`, без заполнения нулями. |
| Три соответствующих `*.metadata.json` | Время создания выгрузки, число строк, состав серий, валюты, методы извлечения, формат и правила пропусков. |
| `.gitkeep` | Пустой технический файл для сохранения папки в Git. |

В длинном формате строка содержит `date`, `ticker`, `currency`, `return`,
`extraction_method`, `currency_kind`, `instrument_id`, `series_id`, `source`,
`quality_flag`, `extracted_at`. Дата — конец месяца; доходность — доля:
`0.025` означает 2,5%. `currency_kind` различает `native` и `converted`.

Источник округляет месячные проценты максимум до четырёх знаков. Точный текст
CSV сохраняет доступную точность, но не восстанавливает недоступные исходные
значения. Parquet `float64` добавляет обычную погрешность двоичного представления.

Экспорты являются снимками базы на момент выгрузки. После `update` их нужно
пересоздать:

```bash
qcross returns export --format csv
qcross returns export --format parquet
qcross returns export --format parquet --wide --currency USD
```

Папка `exports/pairs` отсутствует в обычной структуре. Она появляется только
если явно запросить отдельную пару, например:

```bash
qcross returns export --symbol VTI --currency USD --format parquet
```

Сейчас VTI–USD содержит 2 804 месяца (январь 1793 — август 2026), VTV–USD —
1 197 месяцев (январь 1927 — сентябрь 2026). Обе пары входят в общий набор.

## Logs — текущие журналы

- `returns.log` — импорт, обновление, экспорт и проверка доходностей: запросы,
  методы, переключения, результаты и длительность попыток.
- `discovery.log` — появится при следующем запуске обнаружения каталога.
- При достижении 5 МиБ появляются `.log.1` и `.log.2`; более старые журналы
  автоматически вытесняются. Отдельная папка `history` не поддерживается.

Логи не являются текущим списком загруженных пар. Его содержит отчёт покрытия.

## Reports — рабочие отчёты

| Файл | Назначение |
| --- | --- |
| `lazyportfolio_returns_coverage.csv` | Одна строка на пару: доступность, статус, наличие валидированной серии, метод, начало и конец, число наблюдений, точность, время и причина ошибки. |
| `lazyportfolio_returns_coverage.json` | То же покрытие плюс итоги: 503 готовые пары, 173 через страницы и 330 через бэктестер на момент отчёта. |
| `lazyportfolio_returns_unresolved.csv` | Пары без валидированной серии. Сейчас содержит только заголовок. |
| `backtester_pilot_validation.json` | Подтверждение сравнения VTI/VTV между методами. Используется кодом перед массовым импортом; не удаляется как старый лог. |
| `lazyportfolio_discovery_report.json` | Последняя проверка каталога: категории, валюты, дубликаты, конфликты, предупреждения и результат синхронизации. |
| `latest_validation.json` | Последний сохраняемый отдельный результат проверки серии; заменяется следующим таким результатом. |

`status` описывает состояние попытки, `has_valid_series` — сохранённые данные.
Неудачное обновление может дать `status=failed` при `has_valid_series=True`:
раньше принятая история сохранена. Конец конкретной истории виден в `latest_month`.
Полные проверки принятых импортов также хранятся в `return_series.metadata.validation`.

При явном `backtester-pilot` могут создаваться кандидатные выгрузки в
`reports/pilots`; обычная загрузка таких копий не создаёт.

## Cache — данные для повторной загрузки

- `cache/lazyportfolio/backtester_pairs.json` — действующий список доступности
  инструментов по валютам, прежний `offered_pairs.json`.
- `cache/lazyportfolio/individual_pages.json` — только `urls` с рабочими ссылками
  из валидированных серий, сейчас 173. Старые поисковые записи и псевдонимы удалены.

Метод повторной загрузки выбирается по принятой серии в базе. Наличие URL само
по себе не является статусом загрузки.

## Archive — исходники принятых серий

`archive/validated_sources.zip` содержит только исходные страницы 503 принятых
серий и `snapshot_index.json`. Внутри понятные имена, например
`sources/VTI_USD_individual_page.html`. Индекс связывает их с исходными путями
в базе и SHA-256. Там нет старых неудачных попыток, резервных баз или пробных CSV.

Эти исходники используются для воспроизведения проверки:

```bash
qcross returns validate --symbol VTI --currency USD
```

Архив читается напрямую, без распаковки. Новые HTML выключены по умолчанию;
`--save-raw` создаёт понятный `.html.gz` с тикером, валютой, методом и временем
в `snapshots/lazyportfolio`. Для проверки источника без сохранённого снимка
используется `--live`. Во время импорта данные всегда проверяются до записи.

## Удаление оставшихся материалов расследований

```bash
python -m scripts.compact_data --prune
python -m scripts.compact_data --prune --apply
```

Сначала показывается план. Применение проверяет исходники принятых серий,
пересобирает единственный рабочий архив и только после проверки удаляет старые
архивы, `logs/history`, копии пар и разовые аудиты. Кеш URL обновляется из
валидированных серий. Новые отчёты об этой очистке не создаются.
